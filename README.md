# DONEZO: A simple To-Do App

# Description
This project is the creation of a simple todo app that I titled DONEZO. I used webpack to compile all needed dependencies and modules together. I also used date-fns to format the date of the tasks. Features that include are creation of projects, within such projects are tasks which could be marked as complete or incomplete. You can delete projects and tasks. You can also edit projects and tasks.

## Skills used:
The skills used in making this project possible are:
- Basic HTML and CSS manipulation
- Basic JavaScript DOM Manipulation
- Basic Webpack knowledge in stitching different modules together
- Basic knowledge in deploying a website
